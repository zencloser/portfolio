Project Overview

Agnipath is a Smart India Hackathon 2026 project focused on identifying and classifying industrial fires and persistent thermal sources using satellite thermal-anomaly data and geospatial infrastructure information.

The system combines NASA FIRMS detections with nearby industrial infrastructure information from OpenStreetMap to support the analysis of thermal events and their surrounding context.

The Problem

Satellite systems can detect thermal anomalies, but a detection alone does not establish whether the source is an industrial fire, a forest fire, or another persistent heat source.

The project aims to combine thermal observations with geographic context to help distinguish potentially industrial events from other sources and make the results easier to investigate.

Technical Architecture

The backend integrates satellite detections with nearby geographic features. The system was designed around the following components:

  • NASA FIRMS: Thermal-anomaly records, including coordinates, acquisition date, brightness temperature, fire radiative power, and confidence.
  • OpenStreetMap / Overpass API: Nearby industrial infrastructure features for geographic context.
  • Geospatial processing: Coordinates and nearby infrastructure are used to examine the context of detected events.
  • Classification: A Random Forest classifier was configured as an initial placeholder for future model development.

My Contribution

I worked on the backend, focusing on integrating external data sources and preparing the detection data for analysis and visualization.

  • Integrated NASA FIRMS thermal-anomaly data retrieval.
  • Worked with OpenStreetMap / Overpass API to retrieve nearby industrial features.
  • Worked on backend data structures and frontend-backend integration.
  • Explored a classification pipeline for distinguishing industrial thermal sources from other anomalies.

Current Limitations and Next Steps

The classification model is not yet a trained, validated production model because labeled training data was unavailable. The current classifier configuration is therefore a starting point rather than proof of reliable industrial-fire classification.

Further work includes obtaining labeled examples, training and evaluating the classifier, validating results against ground truth, and improving geographic filtering and monitoring.
