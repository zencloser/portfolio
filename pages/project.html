Overview

The Automated Course Enrollment System is a full-stack University ERP platform built to simplify academic workflows for students, faculty, and administrators. The system includes role-based dashboards, course enrollment, attendance tracking, fee management, and CGPA estimation features using Flask, MySQL, HTML, CSS, and JavaScript. The project was designed to improve my understanding of backend architecture, database management, and real-world web application development.

Main dashboard view — live metrics at a glance

The Challenge

The main challenge was designing a centralized academic management system capable of handling multiple user roles and workflows efficiently.

The platform needed to support secure role-based access for Admins, Faculty, and Students while managing attendance records, course enrollment, fee tracking, and academic data through a structured relational database system.

Technical Approach

The system was designed using a full-stack architecture with Flask handling backend operations and MySQL managing relational database workflows. Separate dashboards and access permissions were implemented for Admins, Faculty, and Students using role-based authentication logic.

The backend structure was organized using modular Flask routes to maintain clean workflow separation and improve scalability. Database relationships were designed to efficiently manage enrollments, attendance records, fee data, and academic information.

Implementation

Implemented core modules including course enrollment, attendance tracking, fee management, and CGPA estimation using Python Flask, MySQL, HTML, CSS, and JavaScript.

  • Role-based dashboards for Admin, Faculty, and Students
  • Attendance monitoring with 75% threshold tracking
  • CGPA estimation and target score calculation
  • Student fee management and payment status tracking
  • Database-driven academic and enrollment workflows

Learning Outcome

Building this project improved my understanding of full-stack development, backend architecture, database management, authentication systems, and real-world web application workflows.

The project also strengthened my problem-solving skills and gave me practical experience working with larger structured applications instead of small standalone projects.
